## Dependencies

polymer imports 'cdtr' (>= 0.2.0) and 'wkpool' (>= 0.5.0), both by the same
maintainer and both on CRAN. polymer contains a C++17 header
(`inst/include/polymer/overlay.hpp`) and compiled code through 'cpp11'.

## Method references

There is no published reference for the method as a whole. It combines a
constrained Delaunay triangulation of all input edges (provided by 'cdtr')
with labelling of the triangles by winding numbers propagated across the
mesh (point-in-polygon labelling is kept as an option); both are standard
computational geometry.

## Example data

The example layers `A`, `B`, `C`, `soil` and `field` are generated by the
scripts in `data-raw/`; no third-party data is included.
